# Common Patterns

## Skeleton Projects

When implementing new functionality:
1. Search for a battle-tested skeleton project.
2. Use parallel agents to evaluate options: security assessment, extensibility, relevance scoring, implementation planning.
3. Clone the best match as the foundation.
4. Iterate within the proven structure.
